DaCameraGirl / agent-platform

Agent Platform

A production-shaped starter for enterprise Slack agents with retrieval, tool calling, Jira automation, confirmation gates, and governance logging.

Open sourceRead docs

Slack Agent

Runs a Slack Bolt app in Socket Mode and supports app mentions, commands, direct messages, and local mock workflows.

Governed Actions

Drafts Jira work from Slack requests and requires explicit confirmation before creating an issue.

Audit Trail

Logs turns, retrieval decisions, tool calls, and correlation IDs so agent behavior can be reviewed later.

Run Locally

npm install
npm run mock

# Slack mode
cp .env.example .env
npm run dev:slack
